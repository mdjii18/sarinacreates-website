# Workspace Rules for SarinaCreates Project

## Required Workflow
1. **Analyze First**: Whenever the user pastes logs, error traces, or reports an issue, thoroughly analyze and inspect the code/logs first.
2. **Explain & Recommend**: Explain to the user what is happening, why it occurs, and propose the exact fix.
3. **Get Approval Before Modifying**: ALWAYS obtain explicit user approval BEFORE making any code edits or executing modifying commands.
4. **Implement After Approval**: Implement the approved solution only after the user approves.
