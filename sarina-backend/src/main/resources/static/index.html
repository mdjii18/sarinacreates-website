How a piece gets made

Mix

Colour, by hand

Each pigment is mixed to a small test batch first — resin shifts colour slightly as it cures, so the mix is never a guess.

Pour

Layer by layer

Wall pieces are built in multiple thin pours rather than one thick one, which is what gives them real depth once cured.

Cure

Days, not hours

Every piece cures fully — usually 3 to 7 days — before it's sanded, sealed and photographed for the shop.
